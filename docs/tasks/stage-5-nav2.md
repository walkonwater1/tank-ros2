## S5-01 · 激光雷达接入

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S4-05 | 是 | 0.5 天 |

**目标**：稳定发布 `/scan`。

**步骤**
1. 选型：RPLIDAR A1/C1 等 2D 雷达，USB 接 RK3588。
2. 确认供电（5V）和串口权限。
3. 安装对应 ROS2 驱动（如 `rplidar_ros` / `sllidar_ros2`）。
4. 配置 `frame_id=laser_link`，与 URDF 一致。
5. RViz 检查扫描与实物方向。

**验收**
- [ ] `/scan` 频率和角度范围正常
- [ ] 方向与实物一致
- [ ] TF `base_link → laser_link` 正确
- [ ] 不遮挡、不震动

## S5-02 · SLAM 建图

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S5-01 | 是 | 1 天 |

**目标**：用 `slam_toolbox` 建出可用地图。

**步骤**
1. 安装 `slam_toolbox`。
2. 配置：`base_frame`、`odom_frame`、`map_frame`、扫描话题、分辨率。
3. 遥控建图，速度放慢，走闭合回路。
4. 观察地图重影、漂移，调整参数。
5. 保存地图：
   ```bash
   ros2 run nav2_map_server map_saver_cli -f ~/maps/home
   ```

**验收**
- [ ] 地图闭合、墙体连续
- [ ] 无明显重影
- [ ] `<map>.pgm` + `<map>.yaml` 可加载
- [ ] 建图过程记录参数

**风险**：雷达安装高度/遮挡、轮式里程计误差、环境动态物体。

## S5-03 · 定位模式（AMCL）

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S5-02 | 是 | 0.5 天 |

**步骤**

2. 启动 `amcl`，配置初始位姿。
3. RViz 用 `2D Pose Estimate` 初始化。

5. 记录重新定位流程。

**验收**

- [ ] 移动后位姿跟踪稳定
- [ ] 被搬动后能手动重定位
- [ ] TF 无跳变

## S5-04 · Nav2 配置

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S5-03 | 是 | 1~2 天 |

**目标**：能发目标点并自主导航。

**步骤**
1. 安装 `nav2_bringup`。
2. 配置 `nav2_params.yaml`：
   - costmap：分辨率、膨胀半径、传感器话题
   - 全局规划器：NavFn 或 Smac
   - 局部控制器：DWB 或 MPPI
   - 行为树：默认或自定义
3. 设置机器人 footprint 和速度限制。
4. 启动 Nav2，RViz 发 `Nav2 Goal`。
5. 配置恢复行为：清代价地图、旋转、后退。

**验收**
- [ ] 目标点可达
- [ ] 遇到障碍能绕行
- [ ] 卡住能触发恢复
- [ ] 速度限制生效
- [ ] 急停可用

**风险**：footprint 过大导致无解、costmap 膨胀过大、定位跳变。

## S5-05 · 导航测试与恢复

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S5-04 | 是 | 1 天 |

**目标**：量化导航成功率，形成可复现记录。

**步骤**
1. 设计测试场景：直线、拐角、窄通道、动态障碍。
2. 每个场景跑 5~10 次，记录成功率、耗时、碰撞。
3. 记录失败原因（定位、规划、控制、硬件）。
4. 调整参数后回归测试。
5. 写一份导航调参记录。

**验收**
- [ ] 3 个目标点成功率 ≥ 80%
- [ ] 无碰撞
- [ ] 失败可复现、可解释
- [ ] 参数变更前后有对比

**产出**：`docs/experiments/YYYY-MM-DD-nav2.md`
