## S4-01 · 编码器方案选型

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S3-03 | 是 | 0.5 天 |

**目标**：在引脚、机械、成本约束下选定编码器方案。

**候选**

| 方案 | 引脚 | 优点 | 缺点 |
|---|---|---|---|
| 带编码器 TT 电机 | 4 路（A/B × 2） | 成熟、便宜、PCNT 直接读 | 需换电机/机械适配 |
| AS5600 磁编码器 | I2C 2 路（地址固定 0x36） | 分辨率高 | 两路需 I2C mux 或分总线 |
| 外部编码器模块 | UART/I2C | 省引脚 | 增加延迟和成本 |

**引脚预算**：当前空闲 IO8/IO10/IO12；若牺牲实体音量键，可再释放 IO2/IO18。

**步骤**
1. 确认电机轴、安装空间、供电。
2. 确认编码器分辨率与最高转速。
3. 画接线和供电图。
4. 决定信号走 ESP32 还是 RK3588。

**验收**
- [ ] 方案在引脚预算内
- [ ] 供电和电平匹配
- [ ] 机械安装可行
- [ ] 记录选型理由和备选

## S4-02 · 编码器驱动

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S4-01 | 是 | 1~2 天 |

**目标**：稳定读取左右轮位置/速度。

**步骤**
1. 用 ESP32-S3 PCNT 做正交解码，或 I2C 读 AS5600。
2. 处理方向、溢出、去抖。
3. 计算轮速：`v = Δticks / dt × 轮周长 / 每圈ticks`。
4. 通过串口或 ROS2 话题发布轮速/位置。
5. 加断线/异常检测。

**验收**
- [ ] 正反转计数正确
- [ ] 低速不丢脉冲
- [ ] 速度噪声可接受
- [ ] 断线时状态可观测

**风险**：中断负载、I2C 阻塞、磁编码器安装偏心。

## S4-03 · IMU 接入

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S4-01 | 是 | 0.5~1 天 |

**目标**：提供角速度和姿态，用于 EKF 和转向修正。

**步骤**
1. 选型：MPU6050（便宜）或 ICM42688（更好）。
2. 接 I2C，确认地址和供电。
3. 发布 `/imu/data_raw`（`sensor_msgs/Imu`）。
4. 做零偏标定和温度漂移记录。
5. 可选：发布磁力计/姿态。

**验收**
- [ ] 静止时角速度接近 0
- [ ] 旋转方向与实物一致
- [ ] 频率 ≥ 50Hz
- [ ] 协方差参数有依据

## S4-04 · EKF 融合

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S4-02、S4-03 | 是 | 1 天 |

**目标**：融合轮速与 IMU，输出平滑的 `/odom`。

**步骤**
1. 安装 `robot_localization`。
2. 配置 `ekf_node`：
   - 输入：`/odom`（轮速）、`/imu/data_raw`
   - 输出：`/odometry/filtered`
   - frame：`odom` → `base_link`
3. 设置过程噪声/观测噪声。
4. 关闭重复的 TF 发布，避免多源冲突。
5. 对比融合前后轨迹。

**验收**
- [ ] `/odometry/filtered` 频率稳定
- [ ] 静止无漂移
- [ ] 转向时航向收敛
- [ ] TF 只有一个发布源

## S4-05 · 里程计标定与验收

| 状态 | 依赖 | 硬件 | 预计 |
|---|---|---|---|
| TODO | S4-04 | 是 | 1 天 |

**目标**：让 `/odom` 的误差进入可用范围。

**步骤**
1. 标定轮径：直行固定距离，比较里程计与实际。
2. 标定轮距：原地转固定角度，比较航向。
3. 记录 3 组以上数据，取平均。
4. 写入 YAML，固定版本。
5. 做 1m 直线、90° 转向、方形轨迹测试。

**验收**
- [ ] 直线 1m 误差 < 10%
- [ ] 原地 90° 误差 < 10%
- [ ] 方形轨迹闭合误差可接受
- [ ] 标定参数和原始数据归档

**产出**：`docs/experiments/YYYY-MM-DD-odometry.md`
